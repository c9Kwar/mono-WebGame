# 숲의 일반 패시브 확장

스킬석 3개 뽑기에 4종을 추가했다. 소유하면 모두 상시 적용하며 최대 Lv.5다. 옥구슬의 한 종 활성 규칙과 기존 보유 레벨·재화는 유지한다.

| 패시브 | 등급 / 개별 확률 | Lv.1 → Lv.5 |
| --- | --- | --- |
| 이끼 숨결 | 일반 / 20% | 이동·전리품 정리 중 최대 HP의 1 → 1.8%/초 추가 회복 |
| 나무껍질 맹세 | 희귀 / 4% | 장비·잠재 포함 방어력 +10 → 18% |
| 수호자 사냥꾼 | 영웅 / 3% | 보스에게 주는 모든 피해 +8 → 14.4% |
| 시든달의 낙인 | 전설 / 0.8% | 모든 보스 변이의 초당 재생 −25 → 45% |

등급별 총 확률은 일반 70%, 희귀 20%, 영웅 8%, 전설 1.8%, 신화 0.2%다. 기존 개별 확률을 같은 등급 내에서 나눈다: 빛의 일격 50%, 숲의 방벽 8%, 응급 재생 8%, 바람의 축복 5%, 생명의 이슬 1%, 새벽의 메아리 0.2%. 중복 강화 성공률과 반환 규칙은 그대로다.

보스 준비 점검은 사냥꾼·낙인을 포함한다. 주기·확률 발동 추가 피해는 여전히 제외하는 추정치다. 이끼 숨결은 전투·쓰러짐 대기·정지 중 회복하지 않는다. 획득 즉시 일반 사냥 준비 점검의 회복 추정도 갱신한다.

검증: 전체 Node 회귀 검사, 10,000개 확률 구간, 신규 패시브 획득·보존·레벨별 계산·실제 재생·회복 제한 검증. 40시드씩 보스 전투에서 패시브 없음 평균 38.295초, 일반 10종 최대 레벨 평균 19.645초(1.95배). 특정 빌드의 표본이며 모든 성장 구간을 대표하지 않는다. Chromium에서 390/800/1440px 실제 뽑기·보스 표시·저장 복원을 확인한다.
