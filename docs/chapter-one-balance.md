# 챕터 1 · 경제와 30단계 완주

2026-10-11. 이 문서가 기존 보스·성장 문서의 수치보다 우선한다. 신규 장비의 T1~T3 제한, 일반 몬스터의 장비 드롭 금지, 잠재 확률과 자동 전투 규칙은 유지한다.

## 골드와 강화

기존 기본 골드에 종별 가산을 적용한다. 슬라임 +10%, 버섯 +15%, 달팽이 +20%, 나방·토끼 +25%, 모든 엘리트 +35%, 황금 보물여우 +40%. 엘리트의 기존 4배, 여우의 20배에 가산하고 장비·수집 배율을 적용한 뒤 정수로 내린다. 낮은 단계에서는 반올림 단위 때문에 표시 증가율이 달라질 수 있다. 화면의 처치 골드와 실제 지급은 같은 함수를 사용한다.

공격·체력·방어의 시작 비용은 각각 30→24 / 45→36 / 55→44 G로 20% 낮췄다. 20레벨까지 비용 성장률은 공격 1.19, 체력·방어 1.17이며, 이후에는 공격 1.10, 체력·방어 1.08로 완만해진다. 30단계에서 진행이 끝나도 강화 비용만 무한 지역을 가정한 속도로 폭증하지 않게 한다. 공속·치명타·이속 비용과 기존 강화 레벨·골드는 변경하지 않는다. 일괄 강화는 같은 가격식을 합산한다.

오프라인 보상은 종별 강화된 HP·방어·공격을 반영한 보수적 생존 검사와 처치 시간을 사용한다. 생존 가능할 때 지역의 일반 몬스터 평균 골드를 50% 효율로, 최대 8시간 지급한다. 보스·여우·엘리트 보상이나 스테이지 클리어를 오프라인에서 추정 지급하지 않는다.

## 일반 전투

기존 단계·종별 HP에 `1.20 + 0.012 × (단계−1)`, 공격력에 `1.12 + 0.006 × (단계−1)`을 곱한다. 즉 1→30단계에서 HP +20→54.8%, 공격 +12→29.4%다. 일반·엘리트·여우의 체급 비율과 공격 간격은 유지한다.

몬스터 방어력의 1단계 기준은 슬라임 2 / 버섯 3 / 나방 1 / 달팽이 8 / 토끼 4 / 여우 6. 단계마다 1.12배, 엘리트는 추가 1.3배다. 피해 감소는 `방어/(100+방어)`, 최대 45%이며 최소 피해는 1이다. 일반 공격·자동 패시브·추가타가 같은 방어 계산을 거치고 흡혈은 실제 감소한 HP에만 적용된다. 보스는 이번 일반 몬스터 방어 계산에서 제외하며 기존 관통·재생·강타로 차별화한다.

## 보스와 보상

| 보스 | 신규 해금 | 일반 HP | 기본 공격 | 기본 골드 | 첫 처치 장비 |
| --- | --- | ---: | ---: | ---: | --- |
| 꼬마 거북 | 3단계 도달 | 7,200 | 60 | 720 (+20%) | T1 수호자의 반지 |
| 돌돌이 | 6단계 도달 | 54,000 | 220 | 3,000 (+25%) | T2 반딧불 길잡이 신발 |
| 몽글이 | 11단계 도달 | 360,000 | 550 | 12,480 (+30%) | T3 이끼빛 정찰검 |
| 루루 | 21단계 도달 | 1,100,000 | 1,050 | 24,300 (+35%) | T3 전설 달깃 탐사 망토 |
| 밤톨 | **30단계 마지막 처치 완료** | 3,000,000 | 1,900 | 50,400 (+40%) | T3 전설 밤톨 원정 망치 |

골드의 변이 배수는 기존 엘리트 ×3, 미스틱 ×12를 유지한다. HP·공격·관통·재생의 변이 규칙도 유지하며 일반 보스의 기본 수치에 적용한다. 해금은 도전 권한이지 즉시 승리 보장이 아니다.

- 돌돌이의 확정 추첨 후보에서 일반 탐험화를 수호자의 바람 장화로 교체했다.
- 루루는 달깃 망토 / 수호자의 바람 장화 / 수호자의 각반 중 하나를 확정 지급한다. 달깃 망토는 전설, HP 310·방어 22로 조정했다.
- 밤톨은 원정 망치 / 여명의 검 / 수호자의 흉갑 중 하나를 확정 지급한다. 원정 망치는 전설, 기본 공격력 +48%다.
- 루루·밤톨의 첫 처치에 해당 전용 설계도를 아직 모르면 확정 지급한다. 이미 발견했거나 같은 처치에서 자연 드롭되면 추가 지급하지 않는다. 이후 기본 설계도 확률은 2.5% / 1.2%이며 기존 60회 미획득 보장은 유지한다.

## 완주·업적·기존 기록

30단계에 **도착한 것**과 마지막 몬스터를 **처치한 것**은 별도 상태다. 마지막 처치 후 `chapterOneCleared`를 저장하고 30단계 반복 사냥으로 전환한다. 31단계를 만들지 않는다. 완주 상태는 사망·재접속으로 취소되지 않으며 챕터 2는 계획 안내만 남긴다.

목표는 3 / 6 / 11 / 16 / 21 / 26 도달, 30 완주다. 골드는 순서대로 300 / 900 / 1,800 / 3,600 / 6,000 / 9,000 / 15,000 G. 완주는 수호자의 핵 6개와 T3 전설 장비 1개를 확정 지급하며, 다른 목표의 기존 확률 장비 규칙은 유지한다. 모두 한 번만 수령한다.

보스 첫 격파의 영구 공격 보너스는 3 / 4 / 5 / 6 / 8%. 6·11·16·21·26 도달과 30 완주마다 기록 공격 +3%p·골드 +1%p를 적용한다. 수집 세트의 기존 최소 3% 규칙은 유지한다.

이전 30단계 초과 저장은 현재 진행을 30단계로 맞추고, 초과 최고 기록은 `legacyHighestStage`에 별도 보존한다. 이전 기록으로 얻은 기록 보너스와 이미 받은 업적·보스 승리·장비·잠금·골드도 보존한다. 기존 최고 31 이상이면 30단계 통과의 근거가 있으므로 완주로 인정한다. 이미 격파한 보스의 재도전 권한은 유지한다. 이전 달깃 망토·밤톨 망치의 1~2줄 잠재는 임의로 재추첨하지 않으며 새로 얻거나 사용자가 재설정한 전설 장비만 3줄을 적용한다.

## 검증과 수치 해석

`tests/chapter-economy-simulation.cjs`는 희귀 장비·패시브 없이 같은 능력치로 비교한다. 강화 한 번의 예상 소요 시간은 기존 지역의 평균 일반 몬스터 골드/처치·이동 시간을 기준으로 계산한다. 실제 계정 전체의 완주 시간 예측은 아니다.

| 단계 / 공격 레벨 | 다음 공격 강화 예상 시간: 이전 → 변경 |
| --- | --- |
| 1 / 0 | 28 → 23초 |
| 3 / 5 | 54 → 40초 |
| 6 / 12 | 172 → 97초 |
| 11 / 22 | 857 → 315초 |
| 21 / 40 | 13,477 → 774초 |
| 30 / 55 | 110,516 → 1,443초 |

30단계의 공격 55·체력 65·방어 60·공속 18 빌드는 빠른 토끼에게 패배한다. 체력 75·방어 70으로 보강하면 승리한다. 즉 강화 구입 간격을 줄이면서도 생존 준비가 필요한 고비는 남겼다. 일반 보스 5종도 준비 부족 패배와 준비된 빌드 승리, 패시브 유무를 기존 실제 전투 루프로 검증한다. 긴 기간의 실제 사용자 플레이 통계는 아직 없다.
