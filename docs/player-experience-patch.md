# 모의 플레이 기반 편의성 패치

## 검사 방법

`tests/player-simulation.cjs`가 실제 `stepCombat`, 강화, 제작, 장착, 원정, 탐사, 업적 코드를 호출한다. 가상 시계와 고정 난수를 사용하며 렌더링·연출·저장 I/O만 생략한다. 새 플레이어의 기본 50골드에서 출발하며 레벨이나 아이템을 지급하지 않는다. 0.25초 단위로 전투를 진행한다.

- 탐험형: 20초마다 확인, 균형 강화·첫 제작·수집 보상 확인.
- 수집형: 45초마다 확인, 첫 제작을 우선하며 장비와 패시브 준비.
- 간헐 접속형: 120초마다 확인, 제작/수집 메뉴는 열지 않지만 전투 화면의 보상 알림에는 반응.
- 보스 도전형: 20초마다 확인, 체력·방어에 더 투자하고 일반 보스 준비 점검을 통과하면 도전.
- 각 성향에 시드 7/42/99, 각각 게임 시간 2시간. 이전 버전 12명과 최종 버전 12명, 합계 **48시간 분량**을 가속 실행.
- 최종 플레이어는 새 일반 사냥 안내가 위험/소모 상태라면 표시된 공격·HP·방어·공속의 증가 효과를 비교해 생존 효율이 나은 강화를 선택한다. 반복 사냥에서 준비가 되면 이정표로 최고 기록에 복귀한다. 이전 버전에는 이 안내·이동 기능이 없다.

따라서 전후 비교는 수치만 바꾼 A/B 실험이 아니라 **기능과 기능을 이용하는 행동을 함께 비교**한 결과다. 실제 사람의 재미, 이탈률, 장기 유지율을 증명하지 않는다. 전투의 가변 프레임·네트워크·렌더링 성능은 이 모의 실험의 대상이 아니며 별도 Chromium 검사로 보완한다.

재현:

```sh
npm run test:players
# GitHub 소스 저장소에서 이전 버전 재현. 해당 커밋의 이력이 필요하다.
SIM_BASELINE=1 node tests/player-simulation.cjs
```

원자료는 `docs/playtest/before.json`, `docs/playtest/after.json`에 보관한다. 선택한 빌드가 모든 플레이 스타일을 대표하지 않으며, 희귀 드롭에 따라 진행 편차가 생긴다. 2시간 실험은 챕터 완주 시간을 보장하지 않는다.

## 발견한 문제와 수정

1. **보상 누락과 메뉴 왕복**: 전투 화면에 작고 정적인 ‘다음 발걸음’ 메모를 추가했다. 돌파 보상 일괄 수령, 교체할 장비의 부위 수, 제작 준비 완료, 반복 사냥 상태를 관련 화면으로 연결한다. 장비는 자동으로 교체하지 않는다.
2. **강적 때문에 되돌아가는 진행**: 기존 표본의 사망 대부분은 엘리트 조우였다. 이제 엘리트·황금 보물여우 패배는 8초 회복하고 스테이지와 처치 진행을 유지한다. 패배한 조우는 전리품·처치 수·탐사 흔적·업적을 지급하지 않는다. 일반 적 패배의 단계 후퇴와 보스 실패 규칙은 유지한다.
3. **죽고 이기기를 반복하면 작동하지 않던 보호**: 최고 기록을 갱신하지 못한 채 일반 전투에서 3회 패배하거나, 최근 10분에 3회 패배하면 반복 사냥을 켠다. 일반 승리 한 번으로 보호 기록이 지워지지 않는다. 새 최고 기록, 사용자의 돌파 재개·지역 이동·보호 설정 변경에서 기록을 정리한다. 보호는 끌 수 있다.
4. **재료 수급과 재도전 동선**: ‘숲길 이정표’에서 도달한 스테이지를 선택하거나 최고 기록에서 돌파할 수 있다. 현재 적과의 전투를 끝낸 후 이동하므로 적 재추첨·즉시 회피 수단이 아니다. 골드·HP·보스 대기시간은 추가 지급/회복 없이 이어지고 해당 지역의 처치 진행만 초기화된다. 보스/전리품 확인 중에는 예약할 수 없다. 예약은 저장·재접속·취소를 지원한다.
5. **제작 목표가 필터에 숨는 문제**: 목표 바로가기는 필요한 설계도를 실제로 보여주고 키보드 초점을 옮긴다. 준비된 목표는 전투 화면에서도 제작할 수 있다. 평소 제작창의 기본 ‘제작 가능만’은 유지하고 목표를 명시적으로 열 때만 필터를 해제한다.
6. **장비 탐색**: 현재 목적 점수순, 교체 후보, 잠긴 장비, 미장착·잠금 제외 필터. 페이지당 24묶음과 기존 잠금/장착/영웅 이상 보호 유지. 일괄 분해는 현재 부위·보기 필터를 따르며 확인 후에만 실행한다. 희귀 후보도 분해될 수 있다는 기존 안내 유지.
7. **불필요한 표시**: 기능 없는 제작 탭 제거, 보스별 대기표는 펼침 설명으로 변경, 모바일 보스 카드와 사냥 제어 줄 축소. 능력치와 관계없는 ‘Lv.’ 표시는 실제 누적 사냥 수로 변경. 반복 사냥 중에는 진행 바도 ‘현재 지역 사냥 목표’로 표시한다.

## 추정과 저장 경계

일반 사냥 점검은 해당 지역 일반 종의 방어·공격 간격, 기본 공격의 평균 치명타와 이동 중 5% 회복을 사용한다. 만피 기준의 참고치이며 실제 다음 전투의 승리를 보장하지 않는다. 엘리트·여우·패시브·회피·흡혈·임시 격앙은 제외한다. 새로운 난수, 피해, 드롭을 발생시키지 않는다.

새 저장 항목은 `fieldDefeats`(최대 3개 시각), `queuedRoute`(도달 범위 안의 목적지/반복 여부)뿐이다. 기존 저장 키, 골드·보유 아이템·옵션·장착·설계도·보스 기록은 유지한다. 미래/과거 시각과 잘못된 목적지는 정규화한다. 미수령 돌파 보상은 단일 수령과 같은 함수를 사용하고 저장된 수령 기록으로 중복 지급을 막는다.

## 검증

- `npm test`: 19개 회귀 파일의 118개 검사와 콘텐츠·이미지·경제 등 6개 독립 검사 통과.
- 새 회귀는 일괄 보상과 재접속, 도착/완주 구분, 특수 패배 무보상, 일반 패배 보호/만료/새 기록, 예약 이동의 재추첨 방지·저장·보스 차단, 제작 목표 노출, 분해 필터, 탭 충돌 시 변경 차단을 확인한다.
- 실제 Chromium 13종 통과. 새 기능은 390/800/1440px에서 실제 버튼·필터·대화상자·새로고침을 사용했다. 기존 저장/전투/원정/제작/장비/모션/아트 검사도 통과했다.
- 모바일 최종 화면과 이정표 화면을 직접 확인했다. 새로운 캐릭터·장비 원화를 만들거나 전투 모션을 교체하지 않았다.
