# 보스와 전리품 · 이끼빛 표본화 연출

기준: `c5174b8`. 기존 여성 모험가·생물·장비 원화와 유화 팔레트를 그대로 사용한다. 보스 강타의 예고 → 확정 결과 → 격파를 구분하고, 전리품은 실제 지급된 항목을 조사 화첩에 남기는 방식으로 표현한다.

보스 강타는 자동 전투의 대상 지정 공격이다. 피할 수 있는 장판처럼 보이는 범위를 새로 그리지 않는다. 공격 준비의 종별 동작은 보존하고, 기존 보스 스킬의 공통 명중 파편은 확정 명중·방어·회피 결과로 대체한다. 일반 공격에 보스 인장이나 큰 효과를 사용하지 않는다.

## 지급과 표현의 분리

피해·회피·방벽 확률·드롭 추첨·보스 제한 시간·골드·장비 지급은 기존 함수를 따른다. 새 모듈은 게임 RNG를 호출하지 않는다. 보스 격파 뒤 기존 1800ms 대기와 18초 자동 복귀도 변경하지 않는다.

획득 영수증은 실제 `lastLoot`와 골드의 복사본을 읽는다. 보상 카드의 신규 연출 권한은 현재 세션에서 지급된 보고서 ID에 한 번만 부여한다. 기록 다시 보기·같은 보고서 재렌더·저장 복원은 정적인 보상 기록이며, 연출이 보상을 다시 지급하지 않는다. 긴 목록의 뒤쪽 카드도 숨기거나 입력을 막지 않는다.

## 좌표·예산·접근성

- 보스 효과는 기존 `contactFeedbackPoint()`의 전투창 CSS 픽셀 좌표를 사용한다. 모험가 SVG 좌표 변환을 공유한다. 레이어 6, 기존 명중 레이어 7, HUD·위험 안내는 그 위에 유지한다. 장식은 `pointer-events:none`이다.
- 보스 임시 그룹은 종류별 1개(강타·격파), 타이머도 그룹당 1개다. 기본 강타 파편 4개·격파 잎 4개, 560px 이하에서는 각각 2개, 간소화/움직임 감소는 0개다. 예고 이름표와 대상 표식은 재사용한다.
- 일반 획득 행은 1개이며 매 지급 이벤트에 교체한다. 보상 모달의 최대 8개 카드만 짧게 움직인다. 새 프레임 루프·추가 텍스처·후처리·블러·오브젝트 풀을 도입하지 않는다.
- `prefers-reduced-motion`과 게임의 연출 간소화를 반영한다. 움직임을 줄여도 예고 시간·강타 결과·격파 상태·획득 품목은 남는다. 화면 숨김·다른 메뉴·일시정지·리사이즈·새 조우·페이지 종료에서 예약과 임시 효과를 정리한다. 최근 전리품 행은 정적인 기록으로 유지한다.
- 목표는 데스크톱과 모바일 웹의 60 FPS이나, 16.7ms는 게임 전체 예산이다. DOM 상한과 종료 시간 검증을 실제 기기 FPS 보장으로 해석하지 않는다.

## 검증 기록

- `npm test`: **156개 통과, 실패 0**. 신규 보스·보상 회귀 9개와 기존 자산·이미지·밸런스 검사를 포함한다.
- 실제 Chromium 브라우저 검사 **7종 통과**: `browser-boss-reward-feedback.py`, `browser-contact-feedback.py`, `browser-skills.py`, `browser-hero-polish.py`, `browser-smoke.py`, `browser-effects.py`, `browser-preparation.py`.
- 신규 검사는 320/390/1440px에서 보스 5종 × 명중·방어·회피, 격앙 시 실제 공격 시계, 검의 접촉과 격파 동기화, 1800ms 보상 대기, 24개 보상 카드의 표시 상한, 새로고침·기록 다시 보기, 연속 발동·취소·장면 전환·페이지 숨김·리사이즈·간소화·움직임 감소를 확인했다.
- 실제 CSS 타임라인의 시작·최대 강조·감쇠·종료를 샘플링했다. 강타 불투명도는 0/62/250/520ms에서 1/1/.40/0, 격파 인장은 0/220/740/1120ms에서 0/.89/.70/0, 획득 행은 360ms에 6px 이동을 마치고 불투명도 1로 정착했다. [브라우저 원시 기록](playtest/boss-reward-feedback.json).
- 기존 PNG/WebP **66개가 기준 커밋과 바이트 단위로 동일**하다.

모바일 검증은 뷰포트 에뮬레이션이다. 이 단계에서는 실기기 GPU·프레임 비용을 측정하지 않았으므로 FPS나 성능 향상을 보장하지 않는다. 운영 사이트 게시는 이 검증에 포함하지 않는다.
