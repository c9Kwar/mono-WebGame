# 모스라이트 · 이끼빛 표본화

2026-10-11 · 캐릭터·생물·장비를 위한 디지털 유화와 복고 미술 방향.

모스라이트는 **오래된 숲 조사관의 표본화첩이 살아 움직이는 세계**다. 젖은 이끼와 숲 생물이라는 기존 정체성에 유화의 물성, 바랜 탐사복, 산화한 황동 관측기구, 식물 표본의 세밀함을 더한다. 배낭을 멘 여성 모험가와 다정한 숲 생물들이 조용하고 신비로운 숲을 탐험한다. 주인공은 서브컬처 일러스트의 정돈된 얼굴과 실루엣에 부드러운 회화적 입체감을 더해, 배경·생물·장비의 유화와 복고 질감에 어울리게 표현한다. 이 문서는 기존 `game-direction.md`와 `art-notes.md`를 보존하면서 이번 아트 개편의 최종 방향을 기록한다. 기존 작은 기사 원화는 보존 자료로 남기며 새 주인공으로 사용하지 않는다.

## 참고에서 가져올 원리

리버스: 1999의 공식 Steam 소개는 20세기 대체역사에 팝아트와 고전 유화를 섞는 방향을 설명한다. 특정 그림의 복제보다 **시대적 소품과 회화적 표현을 하나의 세계로 묶는 방법**을 참고한다. [공식 Steam 소개](https://store.steampowered.com/app/3092660/Reverse_1999/)

공식 사이트에서 캐릭터·배경·갤러리 구성을 확인하고 공개 이미지를 참고 대상으로 살펴보았다. 복고 분위기를 인물·공간·소품에 함께 배치하자는 방향과 아래 팔레트·붓질 규칙은 모스라이트를 위한 자체 해석이며, Bluepoch의 제작 기법을 확인한 사실로 서술하지 않는다. [Bluepoch 공식 사이트](https://re1999.bluepoch.com/en/home/)

Bluepoch는 인터뷰에서 서사와 미술의 논의를 바탕으로 캐릭터를 만들고, 고유한 콘셉트와 독창성을 중요하게 여긴다고 설명했다. 모스라이트도 ‘이 생물이 숲에서 무엇을 지키는가’에서 실루엣과 장비를 결정한다. [Bluepoch 개발진 인터뷰 · RPG Site](https://www.rpgsite.net/interview/15000-reverse-1999-interview-crafting-a-mind-bending-time-traveling-tale-with-eye-catching-character-designs)

외부 캐릭터의 얼굴·의상·포즈·상징물·로고·구도를 가져오지 않는다. 리버스: 1999의 시계·여행가방·도시 서사를 재현하지 않고, 모스라이트의 이끼·씨앗·반딧불·황동 표식에서 새 형태를 만든다. 여기서 ‘학습’은 공개 자료의 미술적 분석과 제작 규칙 적용을 뜻하며 모델 훈련을 뜻하지 않는다.

## 캐릭터와 생물의 고유 형태

게임 이름·수집품·전투 수치는 유지한다. 아래 설명은 새 원화의 시각적 역할이다.

| 대상 | 원화 방향과 판독 단서 |
| --- | --- |
| 여성 모험가 | 나이·체형의 강조보다 친근한 탐험가의 인상과 숲의 분위기를 우선한다. 부드러운 타원형의 동아시아계 얼굴, 균형 잡힌 머리·몸 비율과 밤색 반묶음 머리, 작은 초록 리본. 단색 청록색 여행 코트·크림색 셔츠·갈색 바지와 장화·단순한 허리띠로 구성한다. 반복 자수와 금장 무늬를 없애고 번들거림과 누런 조명을 걷어낸 차분한 색면으로 천과 가죽을 구별한다. 머리카락은 잔가닥 대신 정리된 큰 덩어리로 표현한다. 한 손에는 직선 가드의 검을 들고 다른 손은 배낭 끈을 잡는다. 갈색 배낭과 말아 묶은 담요가 탐험가의 실루엣을 만든다. 투구와 방패는 없다. |
| 이끼 슬라임 | 유리처럼 매끈한 젤리 대신 반투명 이끼 수지 덩어리. 몸 안의 잎맥과 크림색 씨앗 핵, 둥근 낮은 실루엣. |
| 걷는 보라버섯 | 벨벳 자두색 갓, 황토색 포자 주름, 낡은 아이보리 줄기. 갓의 넓은 타원과 짧은 두 다리로 구별한다. |
| 달빛 나방 | 오래된 식물 세밀화의 접힌 종이 같은 날개. 상아색 바탕에 청록 잎맥과 달 모양 안점, 가는 황동빛 더듬이. 넓은 날개와 작은 몸통으로 구별한다. |
| 이슬 달팽이 | 젖은 세이지색 몸, 호박빛 나선껍질, 소박한 잎 모자. 껍질의 나선 하나가 충분히 크게 보이게 한다. |
| 새싹 토끼 | 오트밀색 털, 신록이 자란 길고 비대칭인 귀, 풀잎 목도리. 귀와 뒷발이 주요 실루엣이다. |
| 왕관 쓴 꼬마 거북 | 이끼가 낀 상아색·황동 등갑과 가지 세 개로 만든 낮은 왕관. 작은 왕관과 커다란 둥근 등딱지를 분리해서 읽게 한다. |
| 낮잠꾸러기 돌돌이 | 오래된 숲길의 둥근 회색 돌이 모인 낮고 넓은 수호자. 바랜 노란 균열과 덩굴, 졸린 호박색 눈. 둥근 어깨와 돌주먹이 중심이다. |
| 숲길 대장 몽글이 | 돌돌이와 다른 세로형 나무·뿌리 수호자. 고사리 갈기, 청록 수피, 황동빛 씨앗 가슴. 넓은 가지 어깨와 긴 뿌리 다리로 보스 둘의 원화를 분리한다. |
| 달잠 부엉이 루루 | 자정 남색과 상아색 깃털, 초승달을 닮은 얇은 황동 이마장식. 접힌 날개가 낡은 탐사 망토처럼 보이는 배형 몸체. 눈과 얼굴 원반은 선명하게 둔다. |
| 도토리 기사 밤톨 | 밤색 가시를 가을 잎 붓질로 묶은 고슴도치. 작은 호박철 가슴갑옷, 도토리 왕관, 나뭇결이 보이는 단단한 망치. 낮고 뾰족한 실루엣. |
| 황금 보물여우 | 구리 금빛 털, 크림색 붓자국의 풍성한 꼬리, 옥빛 씨앗 장식. 차분한 몸색 위에 눈·꼬리 끝·작은 황동 방울만 빛낸다. 숲의 희귀한 길잡이로 보이며 날카로운 보석 갑옷으로 덮지 않는다. |

엘리트는 종의 형태를 유지하면서 짙어진 재료색, 황동 식물 문양, 명확한 엘리트 표식으로 구분한다. 모든 종을 같은 보라색으로 덮지 않는다. 보스 변이 역시 도감·이름·기존 등급 표시와 함께 읽히며 색 하나에만 의존하지 않는다.

## 장비와 재료의 연결

| 묶음 | 형태·재료 규칙 |

| 정찰 장비 | 녹청 강철 잎날 검, 이끼 모직과 가죽끈 탐사복, 천과 금속이 섞인 각반, 황동 버클의 가죽 장화. 수공예의 실용성을 먼저 표현한다. |
| 상위 검 | 숲울림검은 나뭇결과 씨앗 핵, 태초의 파수검은 상아 칼날과 고사리 황동 가드. 희귀도를 실루엣·재료 변화로도 드러내고 단순한 색 교체에만 의존하지 않는다. |

| 보스 장비 | 거북 등갑의 육각 면, 돌돌이의 균열 룬, 몽글이의 나뭇결, 루루의 겹친 달깃, 밤톨의 도토리 철판이 해당 전리품에도 반복된다. |
| 재료 | 호박석은 꿀빛 유리, 강화석은 거친 광물, 씨앗은 은은한 생명 핵, 훈장은 압인한 황동, 설계도는 식물 세밀화가 있는 바랜 종이. 장식과 질감보다 물건 자체가 먼저 읽혀야 한다. |

새 생성 원화는 기존 파일을 덮어쓰지 않는 별도 자산으로 추가한다. 캐릭터·아이콘과 숲 배경의 색온도를 통일하고, 전투·도감·장비·보상 화면에서 같은 그림을 사용한다. 원본 경로·제작 프롬프트 요약·적용 범위는 아래 자산 기록에 남긴다.

## 이번 제작 자산과 출처

이번 원화는 모스라이트를 위해 내장 이미지 생성 도구로 새로 제작한 **AI 생성 게임 아트**다. ‘디지털 유화’는 시각적 표현 방향이며 사람이 실제 유화로 제작했다는 뜻이 아니다. 리버스: 1999의 그림을 다운로드해 게임 자산으로 사용하거나 캐릭터를 추출하지 않았다. 이전 PNG·WebP 자산은 덮어쓰거나 삭제하지 않고 보존한다.

생물 시트의 생성 원본은 `/workspace/generated_images/exec-43c88843-7b73-4029-b40c-5e0b6c727bfe.png`, 장비 시트의 원본은 `/workspace/generated_images/exec-6c572c54-4af9-4da5-9b18-ad82cccc55b8.png`다. 두 시트는 각각 1254×1254 RGBA 이미지다. 생성된 칸 간격이 완전히 같지 않아 실제 실루엣에 맞춘 개별 자르기 좌표를 사용하며 원본 시트는 보존한다.

밤톨 연습 망치는 이름에 맞도록 밤톨 보스 원화에서 도토리 망치만 별도 영역으로 표시한다. 장비 시트의 같은 순번 검은 사용하지 않는다. 표시 좌표와 윤곽 마스크만 바꾸며 PNG 원본은 유지한다.
