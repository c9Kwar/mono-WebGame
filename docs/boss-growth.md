# 보스 공략과 장비 티어 · 2026-10-11

보스의 기본 HP를 20%, 공격을 약 10% 높였다. 일반 원정은 60초를 유지한다. 보스 순서대로 방어 관통은 15/20/25/30/35%, 초당 재생은 최대 HP의 0.10/0.15/0.20/0.25/0.30%다. 엘리트는 관통 +10%p, 미스틱은 +20%p이며 기존 HP·공격 배율을 유지한다.

관통은 방어력만 무시한다. 실제 피해는 `max(1, round(max(0, 공격 - 방어 × (1 - 관통)) × 일반 피해감소 × 보스 피해감소))`다. 회피와 방벽 판정은 그대로다. 재생은 살아 있는 보스의 활성 전투 시간에만 적용하고 최대 HP를 넘지 않는다. 일시정지·숨긴 탭·승리·패배·시간 초과에는 적용하지 않는다. 전투 준비 시뮬레이션도 같은 재생 시점과 관통 공식을 사용한다.

`bossRegenPerSecond(id, variant, reduction=0)`의 세 번째 인자는 추후 재생 감소 비율용이다. 현재 장비·스킬에는 재생 감소 옵션을 추가하지 않았다. 후속 기능은 실전과 준비도 양쪽에 동일한 감소값을 전달해야 한다.

## 티어와 저장

희귀도는 잠재 옵션과 장비의 정체성을 결정하며, 티어는 기본 능력치만 높인다. T1~T8의 배율은 `1 + (tier - 1) × 0.20`이다. 예를 들어 옵션이 같은 영웅 검의 T6 기본 성능은 T1의 2배다. 잠재와 가호는 티어에 따라 증폭하지 않는다.

- 사냥: 현재 스테이지 1/6/11/16/21에서 T1/T2/T3/T4/T5.
- 제작: 최고 도달 스테이지 기준으로 같은 구간 적용, 최대 T5. 제작 버튼에 결과 티어 표시.
- 일반 보스: 순서대로 T2~T6. 엘리트 +1, 미스틱 +2, 최대 T8.
- 기존 저장의 티어 없는 장비: T1로 정규화. 기존 능력치·잠재·가호·수량·잠금·슬롯·장비 ID 유지. 저장 키와 버전 유지.
- 장비 목록·툴팁·비교·추천 점수·전리품 상세와 저장된 전리품에도 티어 반영.

## 보스별 전리품

기존 확률 드롭과 전용 재료·설계도 보장은 유지하며, 매 처치 아래 후보 중 1개를 균등 추첨해 추가 지급한다. 새로운 원화나 아이템 종류를 늘리는 대신 기존 27종 장비의 획득 구성을 다양하게 만들었다.

| 보스 | 확정 추첨 후보 3종 |
|---|---|
| 꼬마 거북 | 수호자의 반지 / 숲지기 탐사복 / 반딧불 길잡이 신발 |
| 돌돌이 | 숲지기 탐사 바지 / 수호자의 흉갑 / 숲길 탐험화 |
| 몽글이 | 이끼빛 정찰검 / 여명의 검 / 수호자의 각반 |
| 루루 | 달깃 탐사 망토 / 수호자의 바람 장화 / 별빛 행운 반지 |
| 밤톨 | 밤톨 연습 망치 / 수호자의 흉갑 / 수호자의 각반 |

엘리트는 같은 후보에서 1개를 더 주고 스킬석 3개를 준다. 미스틱은 태초의 파수검/태초의 인장 반지 중 1개를 더 주고 스킬석 10개를 준다. 확정 추첨은 드롭률 배율과 무관하며, 기존 확률 표의 보상과 중복될 수 있다. 첫 격파 장비도 해당 보스의 티어로 지급한다.

## 검증

`npm test`: 회귀 파일 12개 및 콘텐츠·UI·이미지·밸런스 검사 통과. 새 검사는 기존 장비의 정확한 성능 보존, 티어별 추천·저장·제작·사냥, 5종×3변이×3후보, 관통 공식, 재생의 상태 경계, 보상 재접속을 다룬다.

실제 Chromium 검사 6종 통과. 기존 실시간 보스전과 모든 스킬·유화 아트 검사를 유지하고, 티어 비교/저장 복구, 실제 페이지에서 재생/정지/보상 처리, 390/800/1440px 원정 화면을 추가했다. 모바일 원정과 장비 화면을 직접 확인했다.

고정 난수·장비 없는 기존 중반 세팅은 돌돌이(공격 35/체력 30/방어 30/속도 15), 몽글이(46/45/60/20)에서 패배한다. 체력 훈련을 각각 40, 55로 올리면 42.1초, 45.7초에 승리한다. 나머지 준비된 일반 보스 세팅은 40.6~45.8초에 승리한다. 40개 난수 시드의 돌돌이 비교는 패시브 없음 평균 41.43초, 일반 패시브 최대 평균 24.41초(약 1.70배)로 기존 2배 예산 이내다. 이는 대표 회귀 프로필이며 모든 장비 조합의 완전한 밸런스를 보장하지는 않는다.
